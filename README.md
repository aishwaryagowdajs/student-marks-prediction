
# Student Marks Prediction

## About the Project
This is a beginner-friendly AI/ML project that predicts student marks based on study hours using Linear Regression.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Project Steps
1. Load the student dataset.
2. Separate input and output data.
3. Split data into training and testing sets.
4. Train a Linear Regression model.
5. Evaluate the model using the R2 score.
6. Predict marks based on study hours.
7. Visualize actual and predicted marks.

## Dataset
The dataset contains two columns:
- Study_Hours
- Marks

## Example Prediction
The model predicts marks for a student who studies 7.5 hours.

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib scikit-learn
```

Run the Python file:

```bash
python student_marks_prediction.py
```

## Learning Outcomes
- Understand the basics of Machine Learning.
- Learn Linear Regression.
- Understand training and testing data.
- Make predictions using Python.
- Visualize data using Matplotlib.
